# Movie Recommendation App 🎬
A movie app built with HTML, CSS, JavaScript, and TMDB API
A simple front-end project using HTML, CSS, Bootstrap, and JavaScript.  
Fetches movie data from TMDB API and allows users to browse, search, and book shows.
## Features:
- Movie grid display
- Dynamic search
- Responsive design
- Interactive UI components
## Tech Stack:
- HTML, CSS, JavaScript, Bootstrap
- TMDB API
